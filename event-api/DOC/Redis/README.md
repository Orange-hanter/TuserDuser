# Redis — Сводка и навигация

- [Return to documentation menu](../README.md)

Этот каталог содержит документацию по Redis, упорядоченную для быстрого погружения и последующего использования.

Файлы:

- `REDIS.md` — Полное руководство: зачем Redis, архитектура, схемы ключей, примеры использования, CLI и troubleshooting.
- `REDIS_BEST_PRACTICES.md` — Рекомендации для production: конфигурация, HA, безопасность, мониторинг, операции и чеклист.

Как пользоваться:

- Если вы знакомитесь с Redis впервые — начните с `REDIS.md` (быстрый старт, примеры, обзор архитектуры).
- Если готовитесь к продакшн-деплою — открывайте `REDIS_BEST_PRACTICES.md` и пройдите чеклист.

Быстрый переход:

- [REDIS.md](REDIS.md) — Полное руководство (canonical copy)
- [REDIS_BEST_PRACTICES.md](REDIS_BEST_PRACTICES.md) — Рекомендации для production
