## Documentation Menu

This menu organizes existing documents in `DOC/` into topical groups. Files are
kept in their original locations; the links below point to the original files.
Short descriptions under each item summarize what you'll find in that topic
folder.

- [Overview](Overview/README.md) — High-level project overview and visual guide; links to architecture and logging notes.
- [Quickstart](QUICKSTART/README.md) — Hands-on getting-started steps: run the server, example requests, Docker and DB quickstarts, and RBAC quickstart.
- [Architecture](Architecture/README.md) — System architecture, component responsibilities and the discovery engine design.

- [CI / CD](CI-CD/README.md) — CI/CD pipeline docs, checklists and GitHub secrets setup for deployments.
- [Operations](Operations/README.md) — Production runbook: deployment, logging, CORS and Redis operational notes.
- [Integrations](Integrations/README.md) — Integration guides for Telegram, SMS service and Redis usage.
  - [Redis](redis/README.md) — Redis guide and production recommendations
- [Observability](observability/README.md) — Monitoring, logging, and alerting documentation.
- [Security & Authz](Security/README.md) — RBAC implementation details, quickstarts and secret management pointers.
- [Reference](Reference/README.md) — API reference, discovery engine reference and additional menu links.
  - [Discovery-модуль](Reference/DISCOVERY_MODULE.md) — Руководство по работе с модулем персонализированного подбора мероприятий.
