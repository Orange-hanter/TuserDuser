# Чат с авторами в админ-панели - Справка для администратора

## 🎯 Что было добавлено?

В админ-панели появилась функция **живого чата** для общения с авторами событий прямо при модерации. Теперь вам не нужно отклонять событие чтобы оставить комментарий - можно обсудить правки с автором.

---

## 📱 Новые кнопки на карточке события

На каждом событии в очереди модерации появились 4 кнопки:

```
┌─────────────────────────────────────────────────┐
│ Workshop: "Learn Go Programming"                │
├─────────────────────────────────────────────────┤
│ [Approve]  [Chat]  [Request Revision]  [Reject] │
└─────────────────────────────────────────────────┘
```

**Кнопки:**

- **Approve** → Одобрить событие (как было раньше)
- **Chat** 💬 → Открыть чат с автором (НОВОЕ)
- **Request Revision** 🔄 → Попросить доработку (НОВОЕ)
- **Reject** → Отклонить событие (как было раньше)

---

## 💬 Как использовать чат?

### Шаг 1: Откройте чат

Нажмите кнопку **"Chat"** на карточке события.

### Шаг 2: Посмотрите историю

Вы увидите все предыдущие комментарии:

- От администраторов (синий фон, красная полоска)
- От автора (серый фон, зелёная полоска)

### Шаг 3: Напишите комментарий

- Введите текст в поле внизу экрана
- Нажмите **"Send"**
- Комментарий мгновенно отправится автору

### Шаг 4: Закройте чат

Нажмите кнопку **"Close"** в левом верхнем углу

---

## 🔄 Как запросить доработку?

### Вариант 1: Через кнопку "Request Revision" (рекомендуется)

1. Нажмите кнопку **"Request Revision"** на карточке события
2. В модальном окне напишите детальное описание что нужно исправить
3. Нажмите **"Send Request"**
4. Событие переходит в статус **"needs_revision"**
5. Автор видит в своем профиле событие с просьбой доработки и вашим комментарием

**Пример:**

```
Пожалуйста, исправьте следующее:
- Добавьте более подробное описание (минимум 200 символов)
- Укажите точный адрес место проведения
- Добавьте изображение постера
- Проверьте дату и время события
```

### Вариант 2: Через чат

1. Откройте **"Chat"**
2. Напишите что нужно исправить
3. Подождите пока автор ответит в чате
4. Если нужны глубокие изменения → нажмите **"Request Revision"** с полным описанием

## ✅ Рабочий процесс модерации

### Вариант А: Быстрое одобрение


```
Откройте Chat
→ Задайте вопросы автору
→ Получите ответы
→ Approve (если всё ОК) или Request Revision
```

### Вариант В: Доработка с детальным описанием

```
Откройте Chat (опционально, для быстрого согласия)

→ Автор исправляет
→ Approve (когда будет готово)
```

### Вариант Г: Отклонение

```
Event Reject
→ Введите причину
→ Событие закрыто (автор может создать новое)
```

## 🎨 Внешний вид чата

### Чат содержит:

1. **Заголовок:** "Event Comments Discussion" с кнопкой "Close"

2. **История комментариев:**
   - **ADMIN комментарии** - синий фон (#E3F2FD), красная полоска слева
   - **CREATOR комментарии** - серый фон (#F0F0F0), зелёная полоска слева
   - Каждый комментарий содержит: роль автора, время отправки, текст

3. **Область ввода:**
   - Текстовое поле "Type your comment..."
   - Кнопка "Send" для отправки
   - Кнопка становится неактивной во время отправки ("Sending...")

4. **Автообновление:**
   - Чат автоматически обновляет комментарии каждые 5 секунд
   - Новые комментарии появляются без перезагрузки

## 📊 Статусы событий

После действий в админ-панели событие получит статус:

| Действие         | Статус           | Видно автору         | Видно в каталоге |
| ---------------- | ---------------- | -------------------- | ---------------- |
| Chat + Approve   | `approved`       | ✅ Одобрено          | ✅ ДА            |
| Request Revision | `needs_revision` | ✅ Требует доработки | ❌ НЕТ           |
| Reject           | `rejected`       | ✅ Отклонено         | ❌ НЕТ           |

## 💡 Советы по использованию

### Совет 1: Используйте чат для уточнений

Вместо того чтобы сразу отклонить, напишите в чат:

```
"Привет! Событие выглядит интересно, но нужны уточнения:
1. Какой опыт требуется участникам?
2. Какой максимум человек может посетить?
3. Будут ли раздаточные материалы?"
```

### Совет 2: Будьте конкретны при запросе доработки

Вместо: "Доработай"
Лучше:

```
"Требуется доработка:
- Описание должно быть минимум 300 символов
- Добавьте информацию об инструкторе
- Загрузите постер не менее 500x500px
- Уточните, будет ли запись семинара"
```

### Совет 3: Документируйте свои действия

Каждый комментарий остаётся в истории, поэтому:

- Объясняйте свои решения
- Ссылайтесь на правила/политику если необходимо
- Будьте вежливы - автор может пересоздать событие

### Совет 4: Проверьте историю перед решением

Всегда смотрите полный чат перед финальным одобрением или отклонением.

## 🔧 Технические детали

### Новые файлы в админ-панели:

- `src/components/EventCommentChat.js` - компонент чата

### Изменённые файлы:

- `src/screens/PendingEventsScreen.js` - добавлены кнопки Chat и Request Revision
- `src/services/api.js` - добавлены методы для работы с комментариями

### API, используемые в чате:

- `GET /v1/api/creator/events/{eventId}/comments` - получить комментарии
- `POST /v1/api/creator/events/{eventId}/comments` - добавить комментарий
- `POST /v1/api/admin/events/{eventId}/request-revision` - запросить доработку

### Требования на сервере:

- База должна содержать таблицы: `events_blocked`, `event_review_comments`
- Таблицы событий должны содержать колонку `creator_id`
- Активны эндпоинты Creator Events API

## ❓ FAQ

### В: Можно ли удалить комментарий?

О: Нет, все комментарии архивируются. Пишите внимательно.

### В: Что произойдёт если я нажму "Chat" для отклоненного события?

О: Чат будет пуст (они уже отклонены). Фокусируйтесь на текущих событиях.

### В: Как долго обновляется чат?

О: Каждые 5 секунд. Если хотите обновить быстрее - закройте и откройте чат заново.

### В: Если автор давно не отвечает?

О: Отправьте ему напоминание в чате или перейдите к другим событиям. При следующем посещении он увидит ваше сообщение.

### В: Можно ли отправить Request Revision без чата?

О: Да, нажмите "Request Revision" прямо с карточки события.

### В: Что видит автор когда я пишу в чат?

О: Он видит:

- Все мои комментарии в своем профиле
- Статус события (pending, needs_revision, approved, rejected)
- Может ответить через свой профиль
