# Admin Panel - Chat с Авторами Событий

## Описание

В админ-панель добавлена функция чата для общения с авторами событий. Администратор может:

- 📝 Отправлять комментарии авторам
- 💬 Просматривать историю диалога
- 🔄 Запрашивать доработку события с детальным описанием
- ✅ Одобрять, отклонять события или отправлять их на доработку

---

## Интерфейс

### Экран управления событиями (PendingEventsScreen)

На каждой карточке события добавлены 4 кнопки:

| Кнопка               | Цвет      | Функция               |
| -------------------- | --------- | --------------------- |
| **Approve**          | Зелёный   | Одобрить событие      |
| **Chat**             | Синий     | Открыть чат с автором |
| **Request Revision** | Оранжевый | Запросить доработку   |
| **Reject**           | Красный   | Отклонить событие     |

---

## Функции

### 1. Открытие чата с автором

Нажмите кнопку **"Chat"** на карточке события.

**Что вы видите:**

- ✅ История всех комментариев (если они есть)
- 👤 Автор каждого комментария (ADMIN / CREATOR)
- 🕐 Время отправки комментария
- 📝 Поле для ввода нового комментария

**Дизайн:**

- Комментарии от ADMIN выделены синим (`#E3F2FD`) с красной полоской слева
- Комментарии от CREATOR выделены серым (`#F0F0F0`) с зелёной полоской слева
- Комментарии автоматически обновляются каждые 5 секунд

**Как отправить комментарий:**

1. Введите текст в поле внизу
2. Нажмите кнопку "Send"
3. Комментарий появится в чате мгновенно

---

### 2. Запрос на доработку события

Нажмите кнопку **"Request Revision"** на карточке события.

**Что происходит:**

- Откроется модальное окно
- Введите детальное описание что нужно исправить
- Нажмите "Send Request"
- Событие переходит в статус `needs_revision`
- Автор видит в своем профиле: "Требуется доработка" с вашим комментарием

**Пример использования:**

```
"Пожалуйста, исправьте:
1. Добавьте более развёрнутое описание события
2. Укажите точное место проведения
3. Добавьте изображение постера
4. Проверьте орфографию в названии"
```

---

### 3. Отклонение события

Нажмите кнопку **"Reject"** на карточке события.

**Что происходит:**

- Откроется модальное окно с полем комментария
- Введите причину отклонения
- Нажмите "Confirm Reject"
- Событие переходит в статус `rejected`
- Автор видит: "Отклонено" с вашим комментарием

**Пример использания:**

```
"К сожалению, событие не соответствует нашим стандартам:
- Низкое качество описания
- Нелогичное время проведения
- Конфликт с другими событиями"
```

---

### 4. Одобрение события

Нажмите кнопку **"Approve"**.

**Что происходит:**

- Событие мгновенно переходит в статус `approved`
- События появляется в основном каталоге (доступно всем пользователям)
- Автор получает подтверждение на одобрение

## API эндпоинты (используемые в админ-панели)

### Получить комментарии к событию

```
GET /v1/api/creator/events/{eventId}/comments
```

**Ответ:** Массив комментариев с информацией об авторе и времени

### Добавить комментарий

```
POST /v1/api/creator/events/{eventId}/comments
Content-Type: application/json

{
  "comment": "Текст комментария"
}
```

### Запросить доработку

```
POST /v1/api/admin/events/{eventId}/request-revision
Content-Type: application/json

{
  "comment": "Описание что нужно исправить"
}
```

### Одобрить событие

```
POST /v1/api/events/{id}/review
Content-Type: application/json

{
  "action": "approve",
  "comment": "Approved by admin"
}
```

### Отклонить событие

```
POST /v1/api/events/{id}/review
Content-Type: application/json

{
  "action": "reject",
  "comment": "Причина отклонения"
}
```

## Компоненты

### EventCommentChat.js

Основной компонент для отображения чата и управления комментариями.

**Props:**

- `eventId` (string) - UUID события
- `onClose` (function) - Callback при закрытии чата

**Возможности:**

- Автоматическое обновление комментариев каждые 5 сек
- Отправка новых комментариев
- Отображение автора и времени каждого комментария
- Различные стили для комментариев админа и автора

## Сценарии использования

### Сценарий 1: Нужны уточнения

1. Откройте чат с автором
2. Отправьте вопросы/замечания через чат
3. Автор ответит (если возможно)
4. Если ответ вас устраивает → нажмите "Approve"
5. Если требуются значительные изменения → "Request Revision"

### Сценарий 2: Требуется доработка

1. Нажмите "Request Revision"
2. Опишите детально что нужно исправить
3. Ждите пока автор исправит
4. Когда автор отправит исправленный вариант, событие останется в статусе `needs_revision`
5. После проверки → "Approve" или снова "Request Revision"

### Сценарий 3: Событие не соответствует политике

1. Нажмите "Reject"
2. Укажите причину отклонения
3. Событие закрывается и автор не может его редактировать

### Сценарий 4: Быстрое общение

1. Используйте чат для обсуждения деталей
2. Если все хорошо → "Approve"
3. Если нужны правки → обсудите в чате + "Request Revision"

## Советы и трюки

1. **Быстрое общение** - используйте чат для коротких уточнений вместо полного отклонения
2. **Шаблоны текста** - сохраняйте часто используемые комментарии для быстроты
3. **Проверка истории** - всегда смотрите чат перед финальным решением
4. **Автоматическое обновление** - чат обновляется каждые 5 секунд, но вы можете закрыть и открыть его снова для принудительного обновления
5. **Комментарии сохраняются** - все комментарии видны автору в его профиле
